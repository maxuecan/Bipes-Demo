一：数字输出IO %1 设为%2（高低）
from machine import Pin
def gpio_set(pin,value):
  if value >= 1:
    Pin(pin, Pin.OUT).on()
  else:
    Pin(pin, Pin.OUT).off()
gpio_set(0, 0)

二：模拟输出（PWM）输出IO %1 赋值为%2
from machine import Pin
from machine import PWM
pwm0 = PWM(Pin(0))
pwm0.freq(1000)
pwm0.duty_u16(255)
